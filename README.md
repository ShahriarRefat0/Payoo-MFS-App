It’s built with **React**, offering a smooth, responsive, and secure user experience.

## 📘 About the Project

The **Payoo MFS App** replicates core functionalities of mobile financial services like **bKash**, **Nagad**, or **Rocket**.  
It allows users to perform essential digital financial operations seamlessly in a simulated or demo environment.

---

## ✨ Features

✅ Create and manage user accounts  
✅ Send & receive money between users  
✅ Cash-in and cash-out simulation  
✅ Mobile recharge functionality  
✅ Transaction history tracking  
✅ Responsive and clean UI  
✅ LocalStorage-based data persistence (if backend not connected)
